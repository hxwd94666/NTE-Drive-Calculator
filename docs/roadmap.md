# 当前路线图

本文件只保留尚未完成且会影响数据结构、外部能力或功能边界的事项。已实现行为写入 `features.md` 或
`AGENTS.md`；界面微调、历史验收和版本流水账不在此保存。

## 1. 战报与收益画像

当前基础是账号聚合战报和摘要事件。下一阶段仅在 nte-core 提供正式 capability 后接入：

- 逐击分页及稳定事件 ID；
- Buff/Debuff 状态区间；
- 角色、武器、队伍、目标和正式场景快照；
- 基于上述事实的覆盖率、单角色综合边际和实战收益画像。

没有正式上游输入时，不从调试工具样本建立产品数据模型。

## 2. 队伍收益与全局配装

长期目标是把角色直伤边际、环合、倾陷、DOT、队伍增益与装备竞争统一到可解释目标函数，再扩展四人
与八人双队搜索。该阶段必须继续使用不可变快照、官方 ID、唯一 UID 和保存方案 contract，不能在页面
内新增第二套评分事实源。

## 3. 上游待开放能力

- 角色等级、突破、觉醒、武器等级和精炼快照；
- 当前四人队与深渊双队；
- 目标实例、怪物 ID、场景 ID；
- 逐击与状态区间；
- 可公开复现的历史战斗导出。

## 4. 验收原则

新能力先确定 payload、sequence/generation、完整性、错误码和隐私字段，再进入 Integration 与账号库。
任何计划只有落地并通过公共行为测试后，才从本文件移入当前功能文档。

## 5. 云异环模式

云异环模式的游戏界面自动装配仍处于开发中，当前不提供前端开关。实现代码与已验证的输入诊断保留在
`drive_assembly` Integration，问题、当前进度、后续方案和真实环境验收条件见
[云异环模式开发](validation/cloud-nte-mode.md)。在真实云游戏输入链稳定前，自动装配固定使用普通鼠标路径。

## 6. 倒带实机执行

倒带推荐分析、八槽保存和实验性输入链已经接通，但游戏输入执行仍缺少真实环境验收，不作为稳定能力：

- 启动前只捕获前台窗口，尚未识别并确认当前确实位于游戏倒带首页；
- 固定坐标映射、余额/价格 OCR、蓝紫金候选轮廓需要覆盖不同分辨率、DPI、语言和画面设置的实机样本；
- 花费前没有把识别余额、十连价格和计划次数回显给玩家作最终确认；
- 运行中只有 F12 停止，没有页面内停止按钮、阶段恢复或中断后续跑；
- 账号 generation、执行快照和窗口身份尚未形成可复核的任务记录，错误目前只回写按钮提示。

领域层中按成本生成“冲分/综合/省币”多方案的旧入口尚未接入当前 Service/UI。当前公开行为只有
“全面均衡”和“少角冲分”两种策略；引入第三种策略前需先确定正式业务规则和公共行为测试。
## 7. 测试服静态数据收尾

- schema v16 测试服数据集已进入发行静态库，残虹（1036）与灵可（1072）的角色、成长、技能、觉醒、
  装备方案、默认权重和毕业模板可由现有 DAO 读取。后续通过异环工坊 API 原子更新新角色推荐权重并重建
  毕业模板，不在运行时访问 API。
- 当前准备好的 `Content` 只包含角色头像 PNG，没有新增武器 `fork_DemonBlade`、`fork_GoldRecord` 的
  图标导出；资源清单保留正式资源路径并显式标为 unresolved，补齐 PNG 后重新运行 UI 资源构建和
  `tests.test_game_ui_assets`。
