# 界面语言补丁与本机偏好

界面语言由启动时冻结的文本目录提供。导航、账号管理、工作模式与环境、计算与配装、仓库及规则编辑、角色编辑、队伍、战报采集/分析/历史、倒带、养成和资料库的窗口标题、操作按钮、菜单、表头、字段标签、占位提示及固定状态说明均通过实际展示调用方消费目录。标准按钮由组合根把冻结目录交给弹窗外观 owner；弹窗自身目录优先，显式业务文案优先于标准动作默认文字。

显示边界统一投影：文字交给 Qt 控件（标签、按钮、提示、标题、表格/列表项、下拉项、弹窗）显示时，`src/ui/common/display_projection.py` 把已登记为发行中文目录值的整句原文替换为当前语言译文；多行文本逐行匹配，不做子串替换，发行中文目录下为空操作。源码、数据、业务判断、查表与持久化始终使用中文原文，禁止在这些层替换文本。因此服务层与说明表中的固定原文只需登记进目录即可生效；带变量的拼接句改为稳定 key 与命名参数。持有冻结目录的展示代码直接渲染；服务层没有目录时以 `localized_text(None, key, 模板, 参数)` 生成中文，显示边界再按已登记模板整行匹配（模板字面至少两个汉字，取字面最长者），取出变量后套用同 key 译文，变量本身也按整句规则投影。同一原文只对应一个 key，需要按场景区分译法时改用独立 key 渲染。角色/账号/槽位名称、道具及其他正式游戏数据、原始战报、后端异常/算法诊断原文和日志不由界面补丁改写。特别是遗留数值投影使用的正式属性名称仍保持原值，不把译文作为评分字典键。首次数据根选择尚未拥有本机语言上下文时使用发行中文，Windows 原生内容遵循系统语言。

普通标签、消息和表单按纯文本呈现，表单保留标签与输入控件的焦点关联；少量代码控制的链接/强调标记单独渲染，并转义译文、URL及变量。按钮启停、规则配置、范围与排序按稳定 ID 或结构化状态判断，不读取译文决定动作。长文案保留完整可访问名称和提示，规则预算栏在窄窗重排，不将行内操作挤出视口。静态接线核对和离屏专项不代表所有真实屏幕、混合 DPI 或正式外语资源均已验收。
示例伪语言用于长文本验证，不是正式外语发布。鉴定/扫描输入语言的后续处理见
[功能内语言预备](../roadmap.md)，不由界面语言设置控制。

装配结果回看入口已移除；`assembly.status.last_result` 与 `assembly.status.no_result` 仅作为旧语言补丁兼容 key 保留，不再有展示调用方。
队伍选择卡不再展示成员数量；`teams.selection.members_count` 在发行中文与长译文示例中仅作为旧补丁兼容 key 保留，不再由选队界面渲染。

## 操作与生效

- 默认使用发行中文目录；安装补丁只增加或更新本机可选资源，不改变当前语言或自动重启。
- 选择语言后点击“确认语言”只写本机偏好，下次启动加载；运行中的目录保持冻结，不重建账号、计算结果或页面。
- 恢复中文通过选择“简体中文”并确认完成，不再设单独的恢复按钮；不删除已安装补丁、不修改账号数据。
- 补丁无效或缺失时，启动使用中文并给出简短原因，原偏好不被静默改写；未选中的坏补丁不阻断中文启动。
- 文件安装/保存经后台提交通道执行，重复操作不创建并发写；控件关闭和主窗口退出等待已接受提交物理结束。
  主题重启在确认前、确认后和启动新进程前复核待提交任务，忙时只提示稍后重试，不自动续行或退出。

主题与语言共用 `config/global_ui_preferences.json`，分别拥有 `theme` 和 `locale` 字段；单字段读改写保留其他合法字段。
运行期由组合根共享同一个 store，串行合并并同目录原子替换；写入失败保留原件、清理本次临时文件。
首次缺少全局主题字段时才迁移旧账号显式主题或采用新安装默认值，不因文件中已有语言字段跳过迁移。
配置属于本机，不随账号切换或账号导入导出迁移；账号偏好归属维持原有约定。

## 文本补丁格式

发行中文目录在 `assets/locales/zh-CN.json`，用户补丁位于 `ApplicationPaths.locale_patch_dir`。
安装入口只接受 UTF-8 JSON，不执行脚本、表达式、动态导入或网络资源。最小示例：

```json
{
  "format_version": 1,
  "catalog_id": "nte-ui",
  "locale": "en-US",
  "display_name": "English sample",
  "messages": {
    "settings.language.save": "Confirm language",
    "settings.language.saved": "Saved {language}; takes effect next launch."
  }
}
```

这是一份部分覆盖示例，不代表英文界面或英文截图识别已经发布。
基础 key 和各条目的参数以发行中文目录为准；补丁缺 key 回退中文，未知 key、重复 key、参数不一致或格式身份错误整体拒绝。
界面精简后旧说明行与恢复按钮的文本 key 仍保留为补丁兼容数据，但不再渲染；这也包括养成材料准备进度行、仓库匹配作用域小字、选队旧标题以及关闭选择页已移除的底部提示/取消按钮等退役文本。倒带执行确认改用 `rewind.execution.source_changed.*` 后，旧 `rewind.execution.inventory_changed.title/body` 与保存前失效提示 `rewind.execution.save_plan.qmessagebox_2` 同样只作补丁兼容保留。现有补丁不因删控件而失效。
命名参数仅支持 `{name}`，不支持属性/下标访问、位置参数、转换及格式表达式；显示变量按普通文本插入。
显示控件采用纯文本，按钮动作由固定代码与 locale ID 决定，不以译文判断业务。

语言身份限定为保守的标签格式：主语言小写、四字母脚本首字母大写、两字母地区大写，其余片段小写；
`qps` 测试标签统一小写。示例为 `zh-CN`、`en-US`、`zh-Hans`、`qps-ploc`；非规范大小写在写入前拒绝，
避免 Windows 的同名文件覆盖。此约定不是对全部 BCP 47 扩展的支持承诺。
中文基础身份保留，补丁不覆盖发行中文；文件名由合法 locale 构造，不接受语言包自选路径。
解析后的安装目录和目标仍须位于归属配置目录，越界链接和 Windows 保留名不通过。

目录和配置均有输入大小限制，补丁数量、条目与文本长度也受约束；短文件中的深层嵌套、超长整数及非 JSON 数值同样判为错误。
具体上限和格式身份以 `src/integrations/preferences/` 与 `src/domain/localization/catalog.py` 为准，不在文档另记一组易过期数值。
有效目录启动时缓存；渲染不重复读盘，恢复默认不触发模型下载或 OCR 初始化。

## fork 接入方式

文件边界与注入见[系统架构](../architecture.md#24-本机偏好与文本目录)。增加文案时先在基础目录定义稳定语义 key 与参数，
再由展示端消费结构化状态；不在 Service 内拼译文，不翻译数据库主键、协议字段、日志事件码或正式游戏 ID。
组合根将启动时冻结的文本目录显式传给页面、Controller、展示工厂和子窗口；独立窗口缺少注入时使用同一发行中文基线，不读取其他功能的私有服务。`src/ui/common/enum_text.py` 仅为代码内已知说明表建立不可变的基线文案/key 索引，实际译文仍消费本次注入目录，不持有可切换的全局语言或业务服务。用户文本和正式数值字典不进入此适配。新增页面继续使用 `TextCatalog.render`，不建立全界面即时重建框架。前端文案与语言补丁同步维护是 [开发契约](../../AGENTS.md#10-ui日志和可观察性) 的完成门禁。

`docs/examples/locales/qps-ploc.json` 可由真实安装按钮导入，验证长文案、键盘操作及三主题；它不随发行默认语言列表出现。
同样的中文基础目录用于启动夹具，不用内嵌假目录掩盖缺资源。专项、差异与回退证据见
首日架构验证。
实际外语翻译、全页面覆盖、真实窗口/DPI 验收及多语种识别分别验收，不以预备完成替代。

## 覆盖门禁

`tools/quality/check_ui_text_coverage.py` 扫描 `src/` 下除识别词库外的全部业务目录（含集成、存储与求解内核）中可能上屏、但未经目录渲染或登记的中文字面量；日志、docstring、只用于比较或查表的原文、正式游戏名称与识别词库不计。日志之外的内部诊断（带 UID、字段名或解析上下文的异常）与 SQL 语句在所在行标注 `# ui-text: internal`。分享图片的文字不经过 Qt 控件，由分享弹窗在后台渲染期间显式套用同一投影。`tests/localization/test_ui_text_coverage_gate.py` 要求计数不超过 `tools/quality/ui_text_baseline.json`；当前基线为空，新增未登记的中文文案会直接让门禁失败。目录条目与文件体积上限见 `src/domain/localization/catalog.py` 与 `src/integrations/preferences/locale_files.py`。

独立分析组件直接返回的中文说明不在 Calc 源码中，由 `tools/i18n/sync_analysis_core_texts.py --source <组件目录>` 按组件源码快照登记为 `analysis_core.*`（Rust `format!` 占位符转为 `v1`、`v2`… 命名参数），显示时同样按整句或模板投影；组件更新后重新运行该工具，`--check` 可在发布前核对缺口。外部译者协作说明见根目录 [I18N.md](../../I18N.md)。
