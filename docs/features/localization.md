# 界面语言补丁与本机偏好

当前实现是语言扩展预备：设置页的语言卡片及其操作提示使用文本目录，其他页面仍保留既有中文。
示例伪语言用于长文本验证，不是正式外语发布。鉴定/扫描输入语言的后续处理见
[功能内语言预备](../roadmap/architecture-renewal.md#62-鉴定与扫描的功能内语言预备)，不由界面语言设置控制。

## 操作与生效

- 默认使用发行中文目录；安装补丁只增加或更新本机可选资源，不改变当前语言或自动重启。
- 选择并保存语言只写本机偏好，下次启动加载；运行中的目录保持冻结，不重建账号、计算结果或页面。
- 恢复默认只选择中文，不删除已安装补丁、不修改账号数据；仍在下次启动生效。
- 补丁无效或缺失时，启动使用中文并给出简短原因，原偏好不被静默改写；未选中的坏补丁不阻断中文启动。
- 文件安装/保存经后台提交通道执行，重复操作不创建并发写；卡片关闭和主窗口退出等待已接受提交物理结束。
  主题重启在确认前、确认后和启动新进程前复核待提交任务，忙时只提示稍后重试，不自动续行或退出。

主题与语言共用 `config/global_ui_preferences.json`，分别拥有 `theme` 和 `locale` 字段；单字段读改写保留其他合法字段。
运行期由组合根共享同一个 store，串行合并并同目录原子替换；写入失败保留原件、清理本次临时文件。
首次缺少全局主题字段时才迁移旧账号显式主题或采用新安装默认值，不因文件中已有语言字段跳过迁移。
配置属于本机，不随账号切换或账号导入导出迁移；账号偏好归属维持原有约定。

## 文本补丁格式

发行中文目录在 `assets/locales/zh-CN.json`，用户补丁位于 `ApplicationPaths.locale_patch_dir`。
安装入口只接受 UTF-8 JSON，不执行脚本、表达式、动态导入或网络资源。最小示例：

```json
{
  "format_version": 1,
  "catalog_id": "nte-ui",
  "locale": "en-US",
  "display_name": "English sample",
  "messages": {
    "settings.language.save": "Save language",
    "settings.language.saved": "Saved {language}; takes effect next launch."
  }
}
```

这是一份部分覆盖示例，不代表英文界面或英文截图识别已经发布。
基础 key 和各条目的参数以发行中文目录为准；补丁缺 key 回退中文，未知 key、重复 key、参数不一致或格式身份错误整体拒绝。
命名参数仅支持 `{name}`，不支持属性/下标访问、位置参数、转换及格式表达式；显示变量按普通文本插入。
显示控件采用纯文本，按钮动作由固定代码与 locale ID 决定，不以译文判断业务。

语言身份限定为保守的标签格式：主语言小写、四字母脚本首字母大写、两字母地区大写，其余片段小写；
`qps` 测试标签统一小写。示例为 `zh-CN`、`en-US`、`zh-Hans`、`qps-ploc`；非规范大小写在写入前拒绝，
避免 Windows 的同名文件覆盖。此约定不是对全部 BCP 47 扩展的支持承诺。
中文基础身份保留，补丁不覆盖发行中文；文件名由合法 locale 构造，不接受语言包自选路径。
解析后的安装目录和目标仍须位于归属配置目录，越界链接和 Windows 保留名不通过。

目录和配置均有输入大小限制，补丁数量、条目与文本长度也受约束；短文件中的深层嵌套、超长整数及非 JSON 数值同样判为错误。
具体上限和格式身份以 `src/integrations/preferences/` 与 `src/domain/localization/catalog.py` 为准，不在文档另记一组易过期数值。
有效目录启动时缓存；渲染不重复读盘，恢复默认不触发模型下载或 OCR 初始化。

## fork 接入方式

文件边界与注入见[系统架构](../architecture.md#24-本机偏好与文本目录)。增加文案时先在基础目录定义稳定语义 key 与参数，
再由展示端消费结构化状态；不在 Service 内拼译文，不翻译数据库主键、协议字段、日志事件码或正式游戏 ID。
已有公共提示与语言卡片使用同一个 `TextCatalog.render`，新增页面按实际整改范围接入，不建立全界面即时重建框架。

`docs/examples/locales/qps-ploc.json` 可由真实安装按钮导入，验证长文案、键盘操作及三主题；它不随发行默认语言列表出现。
同样的中文基础目录用于启动夹具，不用内嵌假目录掩盖缺资源。专项、差异与回退证据见
[首日架构验证](../validation/architecture-renewal-day1.md#9-本机偏好与界面语言预备)。
实际外语翻译、全页面覆盖、真实窗口/DPI 验收及多语种识别分别验收，不以预备完成替代。
