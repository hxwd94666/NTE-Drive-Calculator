# 倒带推荐「兼顾模式」实现与剩余验收

> 源码已接入独立双目标链路；仅进行必要专项与隔离 UI 验证。未运行完整 core/full、应用打包、安装或真实游戏操作。

## 当前事实源

产品行为、目标口径、共同形状排序、重复份数与定价、独立账号偏好及保存门禁统一见
[兼顾模式功能说明](../features/rewind-dual-target.md)，本文件不再维护第二份算法或界面方案。
原全面均衡、少角冲分继续使用原请求与结果；兼顾模式不改变其阈值、评分和已保存八槽。

## 源码验收入口

| 要求 | 对应专项与可核对行为 |
| --- | --- |
| 两组独立目标、正缺口交集、面积归一及稳定排序 | `tests/rewind/test_dual_target.py`；包含不同组规模、自选目标、已达标、无交集、超八种、重复分配和费用 |
| 来源、占位/缺分、UID 冲突与一致读取 | `tests/rewind/test_dual_target_service.py`；仅使用合成库与固定槽位，变化后整体失效 |
| 独立账号设置、保存失败与提交前取消 | 同上，真实 SQLite 事务下保留旧设置及另一模式方案 |
| 单窗互斥分组、目标改变失效、空结果与手动补齐 | `tests/rewind/test_dual_target_ui.py`；不隐式求解或写游戏 |
| 长译文、三主题与底栏可达 | 同上，仅 Qt 隔离窗口，不宣称真实混合 DPI 验收 |
| 保存及执行前核对冻结来源；执行仅库存变化时可单次确认 | 原严格来源用例保留；本轮新增确认／取消、启动延迟内变化、三模式、再次执行与账号／方案变化用例，尚未运行；输入后端为合成夹具 |
| 三策略同值迁移、草稿/方案隔离、并发冲突、取消、迁移失败重试与晚导入 | `tests/rewind/test_strategy_preferences.py`、三策略 UI 切换及重开专项；仅使用合成账号 |
| 原模式及旧偏好不回归 | 原 `test_shape_recommendation.py`、`test_slot_selection.py`、`test_slot_selection_ui.py`、`test_rewind_slot_preferences.py` 及倒带工具页专项 |
| 语言补丁 | 新文案同时进入发行中文与长译文示例；缺项回退和参数一致性走目录专项 |

专项命令使用质量入口 `tools/quality/run_tests.py core --pattern <专项文件名> -j 1`，不是完整 core。
最终次数和字面输出以当次本机验证记录为准，不将预期清单写成已通过结果。

## 尚待维护者安排的真实验收

1. 重启当前源码，在实际账号选择两组不同角色和保存槽位，分别设置目标；确认生成、调整、保存及重新打开互不串组。
2. 使用一组已达标、无共同形状及不足八槽场景，确认状态说明与手动补齐可理解，不把累计缺口当成毕业率。
3. 真实 Windows 混合 DPI、多屏及用户语言补丁的全状态检查；隔离窗口专项不替代这些证据。
4. 发布前按授权补做完整 core/full、打包与干净安装；本次开发不自行执行。
5. 真实游戏倒带另行授权验收。保存或来源门禁通过不表示已实际抽取装备；原始结果的计划/预计值语义保持不变。

无新增游戏操作权限、自动倒带、掉落概率模型、词条搜索、库存最优搜索或 Rust 组件改版任务。
