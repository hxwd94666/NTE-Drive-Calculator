# 新版数据候选待处理项

本页记录尚未闭合的来源与验收边界；当前已交付功能仍以对应 features 与 reference 文档为准。

正式服同批来源已用于主静态、图鉴与公共技能图片更新；Exe 默认头像／立绘和曳尔沐好感资料在本批来源中闭合。
静态和离线专项通过不等于全部角色机制或实际游戏使用验收完成；dataset、schema、组件版本与来源哈希以实际清单为准。

| 对象 | 缺口及影响 | 完成条件 |
| --- | --- | --- |
| 合并静态候选晋升 | 两条分支的旧迁移编号含义不同；规范构建保留原目标发行迁移并追加缺项与多目标结构，候选已生成。正式主库、图鉴和图片继续使用目标分支已审计的一套数据，不用任一旧二进制库覆盖另一方 | 取得并校验原解包质量报告及其哈希，复核候选的已审查蓝图缺口、来源、两种用途和公共素材，再通过正式晋升入口成套安装；当前审查见[合并核对](../validation/temp-test-merge.md) |
| 原生同步实机验收 | 新角色身份、装备图纸与完整形状投影已在离线专项核对；本次故障的具体运行时触发记录尚未取得 | 使用成套正式组件重新验收角色与背包同步，确认故障消失且异常输入不提交残缺快照；Dump 开发宿主不参与该验收 |
| 低风险抓包新版背包验收与属性目录交付 | 导出器已按源属性全集重建；新增属性的隔离候选单独核对，当前发行 Core 内嵌目录尚未随本次改动重建/晋升。缺少新版背包样本，报文解析到完整快照提交仍待验收 | 在授权范围完成采集目录及 Core 成套交付，版本保持维护者指定值；取得新版样本后验证角色/卡带/驱动、字段单位、状态与装备关系、完整性失败和取消边界，再另行做游戏验收。目录加载或握手通过不替代这些证据 |
| 角色与战报机制覆盖 | 角色表可用与目录映射齐全不代表所有条件技能、召唤归属和固定轴机制均完整量化 | 按角色适配矩阵核对同版逐击证据与模型，未覆盖项继续显式标为未知 |
| 真实 Windows／游戏表现 | 隔离源码及组件专项不等于实际使用验收 | 在另行授权范围完成三主题、角色面板、战报与同步等实际使用验收 |

挑战目标仅记录条件而不判定完成；选择和常驻数值边界见[玩法资料契约](../reference/static-catalog-monster-domain.md)。
