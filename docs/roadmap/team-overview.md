## 后续验收应保持的行为矩阵

- 来源：三种模式；稳定槽位身份；各方案各自来源；完整库存能力与 UID 冲突；切换来源无游戏副作用。
- 指标退役：来源/成员详情不再调用个人毕业模型或展示均值；轴伤毕业无旧值兜底；新指标验收统一由轴伤毕业率开发方案维护。
- 保存：混合优化与合法 B0 分别验凭证，再验证完整共享构筑；方案、借出和队伍结果同事务；取消、故障、重试无半提交。
- 单双队：本队增幅含负值；联合归一指标只在详情；计分覆盖与图纸截断明确；B0 未知不写成零提升。
- 历史：最近不是最高；来源／方案／成员／静态／组件变化标关联，不重算旧值；删除一队不删除联合伙伴及配装。
- 隔离恢复：账号 ID 碰撞、旧回调、来源并发变更；旧库升级失败回滚及重试；旧包默认配置；新版保全后旧版恢复。
- 交互资源：纯文本、键盘、三主题、长内容、混合 DPI、可见队伍优先、取消及本例 owner 物理退场。

完整门禁满足前不将本轮源码专项候选标为稳定发行。
