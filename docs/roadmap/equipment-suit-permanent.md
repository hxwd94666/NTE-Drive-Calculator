# 套装无条件常驻：接入范围与剩余门禁

分类和数值证据唯一维护在[常驻参考](../reference/equipment-suit-permanent.md)及其审查数据。本文区分已经接线、组件交付和仍未完成的消费者，不以源码存在代替安装版验收。

## 当前已接入

- 只读 DAO 从本次静态目录的修改包、Buff Modifier 和装备曲线读取无条件常驻。修改包必须无条件且为加法；Buff 必须 Infinite、单层、无标签/施加要求且为加法。子 Buff 还须有装备开始时无条件自身施加的正式关联。有限时、叠层、触发增益和缺失曲线不补零冒充已确认数据。
- 当前十二套的运行时读取与人工审查金样逐项对照为 17 条。实际数值与来源仍见常驻参考；不在文档或 UI 硬编码第二份常量。
- 公共激活投影以唯一非虚拟核心的正式 `suit_id` 决定套装；驱动本身没有套装归属。只计算真实驱动与 `required_shape_ids` 相交的不同形状，核心不计件数；二件/四件分别激活并各加一次。重复形状、普通虚拟占位不证明完成。
- 角色属性汇总、角色当前配装的直伤与边际输入共用同一投影；攻击/生命/防御分别进入自己的面板分量，暗抗穿只进入暗属性的抗性穿透。治疗/护盾/充能保留专属属性，不伪造为直伤收益。单件基础分、原始装备词条和账号库存不改写。
- analysis 直伤投影接收冻结套装来源和装备身份；候选换核心/形状后重算增量，不能黏住基线套装加成。新增能力 `allocation_suit_permanent_v1` 区分旧组件，协议身份、实际构建与交付状态以随附组件清单和集成核对为准。

当前目标仍是原标准攻击面板期望指标，不因加入生命/防御常驻就宣称标准直伤策略已使用任意技能的生命/防御倍率。原公式和搜索预算不变。

## 已完成的 P0 消费者

- 正式数据已由 `output_current_retry/HT/Content` 重建并通过 schema 45 / importer 63 的正式晋升门禁；正式 dataset 为 `cn_retail_suit_20261113`，包含 24 条效果审核与 17 条常驻属性。旧账号库不会被批量重解释。
- 最终候选暴击上下限已在 Rust 分配、回填、缺件与换图纸路径按每个冻结候选重新判定，避免统一预扣或重复加成；未知来源保持未知。
- 个人毕业模板、角色面板、保存方案汇总、分享和替换均消费同一套装激活投影；理论毕业模块仅接受官方模板形状证明，普通虚拟占位不激活。
- 队伍当前/理论/培养/装备建议与战报重建已接入同一套装来源；已进入面板的同源根 Buff 只去重常驻部分，条件强化仍保留。完整增强失败时可保存已验收的 B0，并带结构化失败状态。
