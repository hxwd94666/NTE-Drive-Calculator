# NTE Drive Calculator 2.0.3 开发索引

## 版本定位

2.0.3 是基于 2.0.2 的战报功能增量版本。它交付 nte-core 摘要型战报、实时悬浮窗、伤害构成和
账号历史持久化，不包含收益画像、综合边际、逐击轴、Buff 覆盖率或队伍搜索。

应用版本的单一事实源为 `src/app/version.py`，本分支固定为 `2.0.3`。账号数据库迁移提升到
schema v13，发行静态数据库 schema 不因本功能改变。

## 合并边界

2.0.3 可以作为 `upstream/test` 的独立候选。合入正式分支前仍按维护流程决定是否补跑自动化、
Windows 人工验收和发布检查；不得因本地运行正常而把未执行的检查描述成已完成。
