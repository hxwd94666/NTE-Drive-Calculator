# 卡带替换评分一致性：审计与修复

## 根因与修复

官方角色替换的基础评分适配器直接将库存主词条的value传给公共评分核，未区分库存百分比原值与评分展示单位，也把实际强化等级带入按品质满级的基础评分。同一满级金色暴伤主词条，库存0.6代表60%，不是0.6%；此前真实组件合成复现同权重分数150变100.5。低等级样本只补百分比转换仍会从150变125，因此本次不是单独乘100补丁。

基础评分适配和角色页边际权重评分适配现在都传递公共核已有的满级语义：main_value为空表示按品质的满级主词条，由唯一ScoringEngine/公共Rust核处理。实际item、百分比、等级、副词条与伤害输入不改。基础权重与动态边际权重保持分离，候选排序/角色卡片使用后者，持久化方案只保存前者，不把直伤收益或边际分当基础分。

替换控制器在冷启动评分器尚未就绪时返回等待，不让展示兼容层的0分回退进入保存。原账号代次、静态来源、选定slot、提交确认、取消与事务路径不变。
