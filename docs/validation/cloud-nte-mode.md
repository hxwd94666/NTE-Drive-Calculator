# 云异环模式开发

## 目标与边界

云异环模式用于解决云游戏窗口中部分鼠标输入不能稳定送达的问题，使自动装配仍能沿用当前账号的已保存
方案、角色列表识别和装配执行器。它属于游戏输入 Integration：页面、Controller 和方案 Service 不持有
云游戏窗口消息、虚拟手柄或鼠标注入状态。

当前模式仅保留实现和诊断，不提供设置入口；自动装配固定使用普通鼠标路径。它不改变方案计算、角色配置、
库存快照、保存方案或装备分配语义。

## 已完成进度

1. **模式状态与路径冻结**：`cloud_nte_mode` 已能在自动装配 worker 启动前冻结并传入角色列表、角色
   遍历和输入执行路径；当前控制器固定该值为 `False`，避免旧账号配置意外启用未完成路径。
2. **角色列表实验路径**：保留手柄 `十字上 → RS` 打开角色列表、指针仅移动唤醒后再用鼠标识别和选择
   角色的动作映射；普通模式继续全程鼠标操作。
3. **装配页实验路径**：保留 `点击空幕 → 十字右 → Y` 进入装配页的映射，并在 `Y` 后插入一次无点击的
   鼠标移动，目标是让云端恢复接收后续卸载、筛选、卡带和驱动的鼠标动作。
4. **可观察性与回滚**：执行器会记录动作名称、手柄路径和鼠标送达诊断；每次实验修改应保存基线、补丁、
   哈希、真实日志和可执行回滚脚本。

## 已观察到的问题

### 1. 鼠标按键状态在云端持续高亮

角色列表的右下角按钮在本机已经完成点击后，云端仍可能显示持续高亮；本机鼠标移动离开时高亮又会熄灭。
这表明云端可能没有完整接收按下/松开序列，或将注入鼠标事件与流式窗口焦点状态错误关联。简单加长按压、
降低移动速度、邻近悬停、改变点击坐标、系统输入与窗口消息双路径、虚拟 HID 鼠标均未稳定解决。

### 2. 手柄操作后首个鼠标动作可能丢失

手柄成功打开列表或进入装配页后，紧随其后的第一个鼠标点击可能不生效。现有实验路径先只移动指针到下一
个真实鼠标操作位置，再等待短暂稳定时间；该动作不点击，不修改游戏状态。其效果仍必须由真实云游戏日志和
人工界面观察确认。

### 3. 同一云端会话的输入能力不一致

角色侧栏滚动、角色列表、滚轮、四叶草按钮、空幕页签与装配按钮在不同时间可能呈现不同的可用组合。
因此不能根据单个成功动作推断整条路径稳定，也不能把一次手柄激活当作全部后续鼠标事件均可用的证明。

### 4. 手柄替代路径尚未覆盖完整工作流

已尝试的 `十字上 → RS` 和 `十字右 → Y` 只是局部页面导航。筛选、卸载确认、卡带选择、驱动筛选与拖拽
仍依赖鼠标。只要这些操作中任一个未送达，整次自动装配都会中断；当前没有把云异环模式标记为可用功能。

## 现有实验方案

当维护者在代码层显式启用实验模式时，单个角色的路径为：

```text
角色列表选择 → Esc 返回角色页
→ 鼠标点击空幕 → 等待页面稳定
→ 手柄十字右 → 短暂停顿 → 手柄 Y
→ 等待装配页加载 → 鼠标仅移动到“卸下已有驱动”位置
→ 原有鼠标装配序列：卸下/确认 → 卡带筛选与装配 → 驱动筛选与拖拽 → Esc 返回
```

多角色时，角色列表重新打开仍使用实验手柄路径；角色选择、列表滚轮和图鉴识别仍使用鼠标。实验模式必须
采用同一 `MouseBackend` 与虚拟手柄实例，不得在页面层临时创建另一套输入驱动。

## 后续开发方案

1. **先建立可复现输入证据**：每一步写入脱敏动作日志：运行 ID、页面阶段、动作类型、目标点、触发时间、
   返回截图路径和动作结果；不记录账号名、UID、截图正文或云服务地址。对同一分辨率、DPI、云窗口模式连续
   重复至少三轮，分别记录成功、首鼠标点击丢失、持续高亮和滚轮无响应。
2. **按页面建立最小输入协议**：为角色页、角色列表、空幕页和装配页分别定义“输入前置状态 → 输入序列
   → 可见后置状态 → 超时/停止处理”。每个协议只允许一种稳定输入机制；缺少确认时停止，不尝试盲目补点。
3. **增加页面状态校验**：在 `RS`、`Y` 和关键鼠标点击后，以已有截图捕获能力验证目标页面特征；未达到
   预期时停止当前角色并保存诊断，不继续执行可能修改装备的拖拽。
4. **隔离并逐步替换输入**：优先验证云端确实稳定接收的最小动作。若鼠标仅在手柄后失效，使用无点击移动
   恢复后再验证；若按钮释放仍无法确认，再评估额外受控输入设备或云平台原生映射。任何新增驱动只放在
   Integration，须有明确安装、关闭、冲突、回滚和跨设备兼容策略。
5. **恢复入口的门槛**：仅当完整单角色路径和至少两角色重入路径均通过真实 Windows 验收，且 F12 停止、
   虚拟手柄释放、普通模式回归和失败停止均通过后，才恢复设置入口。入口默认关闭，并清楚标注实验状态。

## 当前结论

云异环模式已完成输入映射和诊断基础，但真实云游戏中鼠标事件送达与手柄切换后的状态尚未稳定，不能作为
可交付的自动装配功能。设置页面只展示“云异环模式：正在开发中”，普通鼠标模式是当前唯一对用户开放的
自动装配路径。
