# 战报治疗事件

治疗事件是从冻结角色养成、正式技能/动画资产和原始伤害轴派生的独立事实。它不改写原始逐击，也不由
`effective_healing_amount > 0` 反推。来源侧 `BUFF_EVENT_TREATMENT`、目标侧
`BUFF_EVENT_BEING_TREATED`、原始治疗量和最终有效生命变化是四个不同层次；当前协议不能直接观测后
三者时必须保持未知。

## 事件字段与计时

`BattleTreatmentEvent` 保存稳定事件 ID、原始轴时点、来源角色、来源动作、治疗种类、目标范围、证据、
置信度、目标角色、原始/有效治疗量、周期序号和计时依据。事件对象表示一次治疗行为；满血时有效治疗量
可以为 0。瞬时事件跟随正式动画/逐击锚点，周期和治疗触发 Buff 默认使用扣除时停的活动时钟；只有正式
资产带 `IgnoreTimePause` 时才例外。

伤害分析先生成整场治疗事件，再让所有消费者读取同一份不可变事件轴。目前消费者包括：

- 伊洛伊突破 4「交感性神经系统」：每次伊洛伊治疗刷新全队 `DefIgnore=5%`，20 秒。
- 伊洛伊五觉「清晰」：同一事件刷新
  `min((人物 AtkBase + 弧盘 AtkBase) × 15%, 500)` 的全队 `AtkAdd`，20 秒。
- 弧盘「错误的门」：只读取装备者自己的来源侧治疗事件；不再把任意 E/Q 猜成治疗。

安魂曲「噩梦」移层消费目标侧 `BUFF_EVENT_BEING_TREATED`。当前派生事件尚不能唯一确定所有受治疗者，
因此该消费者保留未结构化状态；安魂曲五觉会关闭这项移层。

当前发行静态目录中确认有治疗生产器的角色如下。

| 角色 | 正式治疗生产器 | 当前固定轴处理 |

| 1004 安魂曲 | 五觉每 3 个有效战斗秒按窗口噩梦总伤害的 1.5% 自疗 | 仅窗口存在正数噩梦伤害时生成周期事件；`ceil` 后原始治疗量可计算 |
| 1021 埃德嘉 | 长按 E 每个真实伤害段治疗生命最低队员；Q 领域延迟 1 秒后逐秒治疗当前角色 | 长按 E 只按真实段生成；真理之匙按已推断的本人 E/QTE 与一觉队友 QTE 累计，Q 生成 10～13 跳；受治疗者未知 |
| 1023 白藏 | 法帝娅低血量救援；Q 领域内「祝」字基础自疗；四觉任意新言灵字额外自疗 | 投射物到达、目标血量和逐目标言灵状态未捕获，暂不生成 |
| 1036 残虹 | 三觉且持有「惑」时每秒自疗 4% MaxHP | 复用狩/惑状态轴；零觉按形态与保留时间，一觉后惑整场常驻；每个有效战斗秒生成一次自疗，最大生命可用时计算原始治疗量 |
| 1039 法帝娅 | Q 按释放前生命分支瞬时自疗 | 正式治疗 GE 的精确 Q 时点与释放前玩家生命未捕获，暂不生成 |

1072、1073。1052 的 `Buff_Jin_RecoverHP` 没有正式绑定且两条曲线均为 0，不能生成治疗。1056 是安魂曲
蝙蝠形态，Q 只有六段伤害；逻辑本体 1004 的五觉周期不能改归属为 1056 Q。1091 是资源混杂、技能目录
残缺的异常行，完整设计保持未知。

## 已结构化时点

伊洛伊的正式动画时点为：

| 行为 | 动画事件 | 相对动作起点 |
| --- | --- | ---: |
| 点按 E | `Event.Montage.Player.Skill.1` | 0.498799 秒 |
| QTE 治疗 | `Event.Montage.Player.QTE.2` | 0.784675 秒 |
| Q 即时治疗与周期时钟施加 | `Event.Montage.Player.UltraSkill.1` | 1.925956 秒 |

Q 周期 Buff 持续 14 秒、间隔 1 秒且 `bExecutePeriodicEffectOnApplication=false`，所以即时治疗与周期
第 1 跳是两个事件。理论周期为 `+1s` 至 `+14s`；周期时钟调用真实治疗执行器的 Blueprint/native 中间链
以及第 14 秒端点仍缺运行时逐事件确认，当前事件标为派生而非实测。

埃德嘉 Q 领域以真实 Q 伤害所对应的领域生成点为锚，`+1s` 首跳；检测到其他角色动作后停止生成。真理
之匙仅从本场已有动作累计到三把并在 Q 时清空，不从技能理论次数补造。安魂曲五觉只在每个 3 秒窗口内存在正数
噩梦本体伤害时生成事件，避免把 carrier 初次应用时可能存在的零量执行猜成来源侧广播。

## 仍需运行时事实

- 受治疗目标 ID、治疗前后生命、原始治疗量、治疗效果/受治疗效果及最终有效治疗量。
- `CustomReplyHealthExecution` 在有效回复为 0 时是否对所有角色统一广播来源侧和目标侧事件。
- 伊洛伊 Q 周期第 14 秒端点、梦境复苏及六觉生命设置的事件类型。
- 白藏逐目标言灵状态与救援投射物到达时点、法帝娅 Q 释放前玩家生命分支，以及残虹阵亡时点。
- 零的正向终结能量增量事件，埃德嘉 Q 领域受治疗者，九原清算累计治疗基数。
- `Equipment_008/Buff_Equipment_Heal_4` 的当前正式可达绑定；在证据补齐前不作为伤害 Buff 消费者。
