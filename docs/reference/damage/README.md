# 伤害计算规则（项目金标准）

本目录记录项目当前确认的伤害计算规则。官方静态数据提供技能倍率、等级曲线、伤害属性、固定暴击率、敌方属性和
环合常量；本规则定义这些输入如何进入各乘区。公式以用户确认的项目金标准为准，官方文件用于补齐可追溯的数值，
不以未确认的运行逻辑反向改写项目规则。正式数值计算在独立分析组件中执行，本目录是其规则依据。

百分比在接口中使用小数，例如 `20%` 写为 `0.20`。

| 专题 | 内容 |
| --- | --- |
| [直伤公式](core-formula.md) | 数据可信度、直伤总公式，以及基础属性、增伤、易伤、暴击、防御、抗性和独立乘区 |
| [重放与 Buff](replay-and-buffs.md) | DOT 专属最终乘区、战报逐击 Buff 边际、固定轴配装反事实 |
| [特殊机制](special-mechanics.md) | 噩梦／蚀心／鸩火、环合、倾陷、超杀扣减与最大生命下降结算 |
| [覆盖范围](coverage.md) | 已导入的官方数据、当前范围、已确认映射与默认状态时序 |
