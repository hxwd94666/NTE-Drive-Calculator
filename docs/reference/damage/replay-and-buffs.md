# DOT、逐击 Buff 与固定轴配装反事实

## DOT 专属最终乘区

早雾突破 2 被动「可以吃吗？」由反应扩展
`Buff_Reaction_ZhouAn8_1003` 实现。官方 GameplayEffect 修改的底层属性为 `FinalDamageUp`，但其
SourceTags 与 TargetTags 都要求 `State.Damage.Dot`；项目因此把它建模为语义更窄的
`dot_final_multiplier`，不作为易伤，也不并入可供全伤害消费的独立最终乘区：

```text
N = 本击结算前目标上仍有效的持续伤害状态种类数
DOT 专属最终乘区 = 1 + min(N × 25%, 100%)
```

同一种持续伤害无论叠多少层都只计一种；当前已审计并进入状态重放的种类为噩梦、蚀心、鸩火和浊燃，
对应 `×1.25 / ×1.50 / ×1.75 / ×2.00`。只有目标在本击结算前已经存在可供公式消费的浊燃状态，且本击
属于正式 `State.Damage.Dot` 消费者时才采用。直伤、附着物、倾陷及其他非 DOT 伤害固定为 `×1.00`。

该乘区位于 DOT 公式末端，与该击已有的倍率、层数、面板、增伤、防御、抗性、易伤、独立最终和暴击区
相乘，并且每击只消费一次。所有已识别 DOT 的逐击展开式都显式保留该槽位：被动未启用或条件未满足时
显示 `×1.000000`，满足时显示实际乘数。残虹被动要求的是“施加持续伤害层”，周期 DOT hit 只证明发生了
一次伤害结算，不能据此补浊燃层或刷新状态。固定轴缺少正式施加事件时，只保留近期 DOT 存在性证据，不把
它扩展为完整层数、持续时间或伤害快照。

若正式施加事件缺失或其静态持续时间已经到期，但同一半场、同一目标在本击前 1.5 秒内刚出现该种类的正式
DOT 跳伤，则这条跳伤只作为“本击附近仍存在该 DOT 种类”的短窗证据参与早雾种类计数。它不会刷新该状态
的完整持续时间，也不会反推出层数或补造缺失跳伤；公式说明必须标明该种类来自近期正式跳伤。

## 战报逐击 Buff 边际

原生命中回调中的 Buff 数值只有在对象、半场、实例与连续观测一致，且求值属性和运算绑定完整时才进入公式。
早雾的目标减防使用同目标持续实例的 `DefUp` 数值，进入直伤和倾陷各角色贡献的敌方防御区；不混入角色自身
防御属性。娜娜莉攀墙状态的暴击伤害使用持续实例的 `CritDamageBase` 求值，不把该技能状态误认作常驻被动。
首次或不完整回调保留证据缺口，不反推执行前状态；反事实移除来源后，相应原生状态不能重新进入候选公式。

### 角色培养被动

角色培养被动按本场冻结角色的 `breakthrough_stage` 解锁：第一被动要求突破 2，第二被动要求突破 4；
`1046/1051` 共用主角逻辑规则但保留原始角色 ID。角色基础面板重建不含这些战斗内被动，所以已确认的
被动属性只在逐击 Buff 投影中加入一次。当前可直接量化的规则为：

- 白藏常驻 `AtkUp=20%`，阿德勒常驻 `DefUp=20%`，残虹常驻 `MagBase=100`；
- 法帝娅为全队提供 `HPMaxUp=10%`，其黯星生命汲取只在第一被动已解锁时进入最大生命适配器；
- 零的 Q 获得限定通伤 `25%`，达芙蒂尔「幻影移行」获得限定通伤 `80%`；
- 翳释放 Q 后 15 个有效战斗秒内，兽牙影刺获得限定通伤 `10%`；
- 薄荷驻场期间获得 `DefUp=20%`，切到后台立即移除；
- 哈尼娅黯星结束加攻必须等待逐目标状态真正结束证据；普通黯星伤害 hit 不代替结束事件，当前固定轴不
  数值投影该层；
- 海月每次水母弹命中后获得 `AtkUp=1%`，默认最多十层；六觉把同一状态上限提高到二十层并在 E 结算后
  加十层，所有来源按总层数共同封顶，整组持续 5 个有效战斗秒；
- 真红每次正式盈蓄范围击后获得 `AtkUp=5%`，最多十层，整组持续 30 个有效战斗秒；
- 浔 Q 的正式终结段把原始技能倍率乘 `2`，不进入通伤区，也不影响 Q 的其他段。

以上有限持续时间使用扣除时停的有效战斗时钟。本击触发的叠层从该击结算后开始，不能反向强化触发击。
目标状态、资源循环、召唤生命周期或新增逐击类被动由各自适配器重放；缺少事件证据时保留真实原击并把
机制增量估为 0，不把它们伪装成全局常驻属性。

### 空幕套装

空幕激活条件不是“同套装驱动数量”，而是核心的正式套装 ID 加上属于该核心 `required_shape_ids` 的驱动
形状数量。二件套常驻属性从 `equipment_modify_pack` 读取，并像其他战斗内常驻来源一样加入原始配置和候选
配置各自的逐击公式。四件套使用独立事件规则：

- 失落光芒与音速蓝刺猬在 Q 开始生效，触发 Q 可以消费本次 Buff；影之信条在 E 完整结束后生效；
- 静谧山庄由正式 `BUFF_EVENT_SKILL_AFTER_HIT` 触发，并由普通攻击条件限制；每个普通攻击有效 Hit 后叠一层；
- 森林萤火之心与真红：双生蝶由全队匹配属性的正式伤害事件叠层，每层分别按扣时停时钟到期；
- 迪亚波罗斯、恶魔之血和街头拳王把基础值与条件增量拆成两个加法来源，“提升至”不重复加入完整高档值；
  迪亚波罗斯装备者的 QTE 即使本体按直伤归类，只要正式攻击类型明确为 `环合·黯星` 或 `环合·浊燃`，
  仍在该次 QTE 结算后开启额外 12% 对应属性穿透，和常驻 12% 合计为 24%，持续 20 个有效战斗秒；
- 小小大冒险的 Q 直接生成十层；普通扣血路径在不能确认受击者就是装备者时不从敌方或队友受击反猜；
- 守卫王国四件套和缇娅的夜间酒馆四件套只改变护盾/治疗，固定伤害轴不凭空生成后续联动。

黯星状态可由结算击向前回填 5 个有效战斗秒，延滞结算按基础 5 秒向前回填。浸染的 12 秒反应状态目前只供
已登记装备条件识别；官方伤害消费者已经确认是区间内团队后续伤害，环合强度逐击取实际伤害来源角色，
但生产固定轴尚未接入该最终乘区。
当前区间没有敌方实例键，因此恶魔之血的条件增量在单目标战报中可直接使用，多目标中属于低置信结构化
估计；以后由逐目标封包或运行时 Buff 状态覆盖。

真实战报伤害已经包含当时 Buff，不再把 Buff 完整乘一次。对属性改动做反事实时，同一击的安全动态
Buff 同时加入冻结面板和改动后面板：

固定轴基线先按战报当前生效指针解析：存在已启用修改副本时，先用原始冻结轴重建副本逐击公式、生命上限
事件和其他派生结算，并把投影结果物化为当前生效基线；没有启用副本时才直接使用原始冻结快照。原始快照
始终不可修改，但启用副本后只承担审计、恢复和物化来源职责，不再作为后续草稿的收益分母。边际页未修改
任何草稿字段时，候选与当前生效基线完全相同，角色和全队收益必须为 `0`；只有实际变化的草稿才计算
“草稿 / 当前生效基线 - 1”。

```text
逐击反事实伤害
= 真实逐击伤害
× 乘区(改动后面板 + 该击动态 Buff)
/ 乘区(冻结面板 + 该击动态 Buff)
```

这里的真实逐击伤害采用原始结算量：属性边际、配装反事实和移除 Buff 的收益不按剩余血量截断，
也不扣除超杀；重复结算与共享血量别名修正仍然排除。该口径仅用于计算收益，战报实测摘要、有效扣血、
超杀和原始轴保持各自事实，不能用反事实结果覆盖实测 DPS。
这会保留同一加法区间的边际递减。逐击目标画像必须按
`(scope_half, target_id)` 从冻结实例映射取得；`default_monster_id`、可能身份列表和主要目标只供展示或审计，
不能替代该击画像。身份未知但画像等价不影响公式；画像未知时，候选前后不变的防御、抗性和其他未知共同
乘区可以在比值中相消，只要求本次实际改变的依赖具备输入。冻结配装常驻属性已在面板中，必须排除；自定义
Calculation、层数不明、非加法操作或未映射乘区若随候选变化，则形成量化缺口而不是默认零变化。

每个逐击反事实同时返回量化状态、已量化比值和依赖缺口：

| 状态 | 数值语义 |
| --- | --- |
| `complete` | 本次相关变化全部进入比值，可以作为完整收益 |
| `partial` | 只包含已有输入支持的变化分量，不代表完整收益，也不默认是下限 |
| `unavailable` | 相关变化无法量化，没有候选比值 |
| `not_applicable` | 已证明本次变化与该击无关，精确比值为 `1` |

未知、缺少画像或缺少 Calculation 不得用 `ratio=1`、候选等于原值或 `0%` 表达。固定轴为了审计可以保留
原始逐击作为未投影占位，但该占位不进入完整候选收益。量化率是得到可用投影的原始伤害占全部相关原始伤害
的比例；变化完整性由上述状态表达。高量化率仍可能包含 `partial`，低量化率也不等于已量化分量不可信。

选定时段的单 Buff 收益使用相反方向的移除反事实。同一稳定 Buff 来源的全部刷新和叠加区间一起移除，
其他配装、Buff、目标、动作、逐击与时段保持不变：

```text
无 Buff 逐击 = 原始实测逐击 × 无 Buff 公式期望 / 当前公式期望
无 Buff 时段伤害 = Σ(无 Buff 逐击) + 联动生命上限结算 + 其他固定派生结算
Buff 伤害增量 = 当前时段有效伤害 - 无 Buff 时段伤害
Buff 时段收益率 = Buff 伤害增量 / 无 Buff 时段伤害
```

这里展示的是该 Buff 对全队当前时段的独立贡献，不是 Buff 面板数值本身。例如只覆盖部分逐击的 15% 通伤
不会自动显示为 15% 的团队收益。安魂曲五觉生命上限结算继续跟随已归因噩梦逐击的移除比值；其他无法安全
随 Buff 移除重放的逐击和派生结算保持实际值。每条已量化逐击按其正式 `character_id` 归到实际造成伤害的
受益角色，而不是默认归到 Buff 来源角色：

```text
受益角色获得伤害 = Σ(该角色当前逐击 - 该角色无 Buff 逐击) + 已归因联动结算差
受益角色自身提升 = 受益角色获得伤害 / 该角色无 Buff 伤害
受益角色折合全队贡献 = 受益角色获得伤害 / 全队无 Buff 时段伤害
```

所有受益角色获得伤害加上无法归因部分，必须严格等于该 Buff 的全队伤害增量。来源不明的派生伤害单列，
不反猜给 Buff 来源角色。各 Buff 都是在完整当前配置上逐项独立移除，存在覆盖重叠、同区稀释、暴击上限或
条件交互时不可直接相加。

所有带持续时间的静态 Buff 都使用扣除时停的有效战斗时钟计算终点，不只妖刀叠层与噩梦特例。残虹、
安魂曲等角色在 Q 时停前后触发的 Buff 会在原始时间轴上相应顺延；显式移除事件仍以其真实发生时刻立即结束
区间。蚀心和鸩火的 30 秒目标状态同样使用扣除时停的有效战斗时钟；时停期间状态时间不流逝。

残虹零觉使用独立的形态状态适配器。现实形态的「狩」向自身通用增伤区加 `25%`；幻境形态的「惑」向
全队持续伤害暴击伤害加 `25%`，但只投影到带 `State.Damage.Dot` 语义的噩梦、蚀心、鸩火和浊燃，不能进入
普通直伤。幻境持续时间、现实切幻境后的旧状态保留时间、幻境切现实后的旧状态保留时间均从
`DT_ZankouEffectFigure` 的 `ZankouMagicDur`、`ZankouRtoMRetainBuffDur` 和
`ZankouMtoRRetainBuffDur` 读取。形态边界由绯影闪、离魂错、Q、换人以及现实/幻境专属 GE 共同推算；技能
动作存在动画尾段或与下一角色动作重叠时，切形态时点优先取该动作 `evidence_event_ids` 中最后一击，而不是
动作展示窗终点。时长统一扣除时停；一觉不复用这套 25% 区间，而由整场常驻的狩 40%/惑 50% 接管，切形态
与离场均不移除。三觉生效时，正式惑 Buff 的 `Period=1s` 和 `MaxHPRecoverHPExecution` 每个有效战斗秒生成
一次残虹自身 `MaxHP×4%` 治疗；时停期间周期暂停，缺少玩家阵亡事实时投影到战斗结束。

本场选择的魔女赐福属于用户确认的外部条件，从战斗开始覆盖到结束。攻击、暴击、暴击伤害、通伤和原质
驱力使用同一安全加法属性投影进入逐击；历史战报不读取当前日期状态。蓄质速率和其他未被伤害公式消费的
属性仍保存选择，但不会产生虚构伤害增益。

## 固定轴配装反事实

角色养成、弧盘、空幕、驱动、技能等级或手工面板属性改变时，第一阶段固定原战报的动作、逐击、目标、
Buff 时段和分析范围，不凭空生成新的动作或命中。原轴每一条对敌逐击必须得到候选值，不能因缺少专用
适配器而从队伍总量中消失。

动作识别把正式 `GA_*_Appear` 作为进场/G 动作，即使它复用了普攻或下落攻击的伤害 GE；该归类只修正
动作身份和 G 专用触发，不改变原始逐击的倍率父级、时间或伤害事实。

灵可同频合击不得继续用单一 `source_character_id` 混写全部身份。派生公式证据分别保存执行角色、倍率定义
所有者、面板所有者、技能等级所有者及伤害属性来源。当前实现采用、但仍待原生事件或实机反事实验证的计算投影为：队友 QTE
保留队友伤害项倍率定义；面板和有效技能等级读取灵可及 `GA_Radio072_QTE`；属性按发起角色的发行静态
`character.element_type` 派生，并明确标记 `initiator_character_static_profile`，不得冒充 Core 动态元素。
FrontToLTE/BackToLTE 等派生伤害只通过正式 `FollowSkillClass` 关系继承等级，不改写自身 Ability 身份。
属性边际以 `formula_panel_character_id` 选择同频 QTE，E 响应和 `QTE → LTE` 推论使用同一公式所有权规则；
推论置信度必须独立保留。若同频 QTE 同事件产生覆纹，面板变化先改变 QTE 实际伤害基数并同比联动覆纹；覆纹
环合强度所有者仍按配对原伤害的原始执行角色解释，直至原生来源字段或实机反事实提供相反证据。

该投影必须挂在版本化同频推论上。完整 E 四段与唯一同目标 QTE 可形成中置信 E 推论；QTE 后 150ms 内
唯一同目标 `GA_Radio072_UltraSkillLTE_AOE` 配对可形成低置信同频响应推论，但不直接命名 E/Q 触发来源。
若另有覆盖完整配对的 nte-core 记录区间，配对推论最多升到中置信；若区间本身由 Q 动作回退则仍为低置信。
时停区间、type6 或 `State.Damage.QTE` 均不能单独证明触发，也不能证明 `SourceAttributeComponent`。
原始逐击角色、伤害构成和泳道始终不改写。

灵可一被动的两部分独立结算：覆纹基础追加率为 `30%`；目标受覆纹影响时，具有正式 `XieTongDamage`
标签或被版本化同频推论限定为追加攻击公式消费者的逐击，在既有
`DamageUpGeneralBase` 加法区额外 `+10%`。后者进入逐击 `damage_up` 因子和 Buff 逐项移除收益，不能并入
30% 覆纹基础追加率，也不能按“所有 QTE”粗放触发。覆纹自身的限定通伤按下文覆纹公式单独加算，不改写原伤害金额。灵可二被动从派生同频 QTE 的首击时刻开始，
对同一目标按发起角色属性施加 `DamageResist<Element>Base - 8%`，该首击本身已经消费减抗，持续 12 秒有效战斗时间；同一目标的同属性只刷新、不叠加，
不同属性分别维护且每种属性同时至多一层。

觉醒固定轴按正式选择双向重放：觉醒二把 `GE_Player_Radio072_UltraSkill3_Damage` 与
`GE_Player_Radio072_UltraSkill3_Damage_level2` 作为普通/强化 Q 爆发互斥变体，新增和移除觉醒都重新选择
对应 GE；三觉共鸣的技能等级 `+1` 和自身 `AtkUp +20%` 由同频 QTE 的灵可技能等级/面板身份消费；觉醒六
`CritBase +25%` 只在 `formula_context_kind` 为灵可同频合击时应用。六觉共鸣由
`GA_Radio072_UltraSkill` 的 Q 事件开始建立 13 秒有效战斗时间团队区间，分别提供
`DamageUpNatureBase +30%` 与 `DamageUpIncantationBase +30%`，时停区间不消耗该持续时间。觉醒一的攻击
间隔、觉醒三的 E 冷却重置、觉醒四/五新增命中或反应、觉醒六资源回复均会改变动作或命中集合，固定轴不
生成这些反事实事件；没有可靠运行时证据时保持未量化。

结构化逐击同时存在当前生效基线与候选配置的预计值时：

```text
逐击比值 = 候选配置预计值 / 当前生效基线预计值
候选逐击 = 当前生效基线逐击 × 逐击比值
```

基线逐击已高/中置信识别为暴击或非暴击时，基线与候选预计值必须使用同一个已识别分支；候选重放不能因为
更接近同一条原始实伤而重新选择分支。原击分支仍不唯一、但伤害渠道的暴击策略已确认时，双方统一使用期望
公式；暴击策略未知时不强行选最近分支，降级到后续估计梯级。`corrected_expected_damage` 只供误差展示，
不得作为基线/候选公式比值的分母或分子。

这样以实测伤害为锚，系统性目标误差和尚未解释的共同乘区不会被重复带入候选绝对值。结构化逐击不可用时，
只可在依赖语义明确的范围内选择第一个可用比值：

1. 同一角色、同一稳定技能、同一伤害属性、分类和公式家族中已结构化逐击的稳健比值；
2. 同一角色、同一伤害属性、分类和公式家族中已结构化逐击的稳健比值；
3. 基线与候选角色面板中已证明目标无关的攻击、暴击期望和通用/属性增伤比值；
4. 该角色其他公式家族和因果依赖相同的已结构化逐击比值。

任何包含防御、抗性、目标 Debuff、血线或其他目标依赖的 peer 比值都必须保持同一
`(scope_half, target_id)`，不得跨目标、跨半场或回退主要目标。完全无法量化时标为 `unavailable`；若只是
部分变化缺少输入则标为 `partial`。原击可在时间轴中保持为未投影占位，但不因此获得数值比值。

已归因生命上限结算优先按已知来源机制联动；证据不足的其他派生结算只按原值保留轴上事实并标为未投影，
不纳入完整候选收益。于是：

```text
完整候选总伤害 = Σ(所有 complete 逐击 × 所选比值)
             + Σ(可联动生命上限结算 × 来源机制比值)
             + Σ(已证明 not_applicable 的原始逐击或固定派生结算)
候选 DPS = 候选总伤害 / 原分析时段有效时长
总收益 = 候选总伤害 / 当前生效基线有效伤害 - 1
结构化重放占比 = 采用基线/候选逐击公式比值的基线伤害 / 当前生效基线有效伤害
量化率 = 具有 complete 或 partial 投影的相关基线伤害 / 全部相关基线伤害
Buff 团队伤害覆盖率 = (逐击公式投影实际应用该 Buff 的基线逐击 + 与其证据联动的生命上限结算) / 当前范围团队有效伤害
Buff 角色伤害覆盖率 = (逐击公式投影实际应用该 Buff 的该角色基线逐击 + 与其证据联动的生命上限结算) / 当前范围该角色有效伤害
关联面板伤害 = 属性关联基线伤害 / 当前面板关联伤害
面板关联伤害 = (当前角色归属伤害 + 由当前公式面板控制的外部逐击) / 当前范围团队有效伤害
关联全队伤害 = 属性关联基线伤害 / 当前范围团队有效伤害
伤害加权当前面板属性 = Σ(关联伤害 × 该伤害发生时的角色侧有效属性) / Σ关联伤害
```

属性单位候选只来自金色驱动可刷副词条目录。空幕主属性另建固定轴候选矩阵：当前 `core` 的识别不限制品质，
但候选值一律取官方金色 20 级主属性曲线。固定当前空幕的套装、副词条和其余装备字段后，令 `N` 为移除当前
主属性的投影、`C` 为当前配装投影、`G_p` 为装入金色满级主属性 `p` 的投影，则：

```text
主属性 p 的独立贡献 = G_p - N
主属性 p 的换装收益 = G_p - C
```

当前主属性与 `p` 同类但品质或数值低于金色满级时，`G_p` 仍是独立候选，不能把换装收益短路为零。

弧盘固定轴综合收益使用 A/B/C 三态分解。A 移除弧盘的成长、常驻属性和技能机制；B 在 A 上只恢复当前完整
弧盘解析出的最终常驻面板差；C 为当前完整弧盘。三段均以 A 态伤害作为百分比展示分母：

```text
弧盘常驻收益 = B - A
弧盘技能/机制收益 = C - B
弧盘综合收益 = C - A
闭合差 = (B - A) + (C - B) - (C - A)
```

该分解只改变固定轴内可量化伤害，不生成轴外动作、命中或循环；未知机制继续按 `partial`/`unavailable`
保留缺口。团队 Buff 移除表是机制来源明细，不可再与弧盘三态结果相加。

只有全部相关变化均为 `complete` 或 `not_applicable` 时，上式才产生完整候选总伤害、DPS 和总收益。存在
`partial` 时只能另列“已量化变化下”的投影及缺口；存在 `unavailable` 时不得补造完整总收益。结构化占比
描述方法证据，量化率描述可安全计算收益的伤害范围，Buff 伤害覆盖率描述效果时段与对象实际罩住的原始伤害，
量化状态描述变化完整性，四者分别聚合。有效属性等于当前生效面板属性加该伤害时刻安全投影的动态属性 Buff；
联动生命上限结算继承其正式来源逐击的属性，倾陷仅按已归属给该角色的贡献加权。无法安全解析属性或归属时
加权平均显示未知，不用零补齐。`team_others` 的逐击角色未知或作用域未知时，可能覆盖的伤害单列为
未判定比例，不并入确认覆盖率。逐击误差和依赖缺口留在审计
结果中，主页面按状态显示完整收益、已量化分量或 `—`。

生命上限派生事件若已有 `source_character_id`，继续计入该角色的候选贡献和伤害构成；没有归因时仍进入公共
未归因项。安魂曲五觉已有实测结算时，以实测有效生命损失为固定轴锚点，按其 `evidence_event_ids` 中对应
噩梦逐击的候选/原始伤害比联动；比值为 1 时必须严格保持实测基线，候选未激活五觉时归零。候选新激活五觉
但没有对应实测下降时，新增 `候选噩梦伤害 × 200% × 结算时目标生命比例` 的候选结算；缺少可靠生命比例时
使用 50% 期望并明确标记为估算。这笔结算仍进入角色和全队候选伤害，不作为零收益忽略。法帝娅被动按候选/
原始冻结来源当前 `source_max_hp` 比联动。来源公式或配置证据不足的事件只在调整后逐击轴固定原值并标记未投影，
不进入完整候选收益。调整后逐击轴
保留原时间与动作，把每个正式逐击和生命上限结算替换为候选值，并同步重算技能条、动作汇总和角色贡献。
候选逐击详情中的“预计提升/下降”定义为：

```text
预计变化 = 调整后候选逐击 - 原始实测逐击
预计变化率 = 预计变化 / 原始实测逐击
```

这是固定轴反事实变化，不是候选公式相对原始实测值的模型误差。原始/候选结构化公式值和实际采用的估计
梯度分别展示，避免把系统性公式偏差误认成配装收益。
