# 卡厄斯

### PASSIVE-1071-GA_Chaos_Passive_1：未迟到的正义

- 目标的「延滞」状态解除时，由卡厄斯对该目标造成一击基础倍率 `800%` 的相属性反应伤害。重复施加延滞
  会重置本次延滞的持续时间。
- 超过基础 5 秒后，额外持续时间按小数秒连续计算，不向下取整：

  ```text
  最终倍率 = 800% × [1 + min(300%, 45% × max(0, 延滞持续秒数 - 5))]
  ```

  因此增幅上限时为 `800% × 4 = 3200%`。
- 该伤害经过相属性增伤、防御区、相抗性区、易伤区及适用的独立乘区。MVP 项目规则按 `不暴击` 重放，
  已经用户同意采用；游戏事实仍缺少强证据，后续可由运行时暴击标记覆盖。

### PASSIVE-1071-GA_Chaos_Passive_2：重点关注！

- 「追缉许可」基础效果是卡厄斯攻击带标记目标时获得 `+20%` 角色限定通用伤害提升；本被动把该数值替换
  为 `+30%`，不是在 20% 上再叠加 30%。
- 只作用于卡厄斯本人对当前带「追缉许可」目标造成的伤害。多目标时每个目标独立维护标记和持续时间，
  未被标记目标以及其他角色对标记目标的伤害均不采用该增伤。

### AWAKEN-1071-Effect1：灼见

- 卡厄斯攻击带「追缉许可」的目标并实际获得罪状时，把该次攻击原本获得的罪状乘 `1.4`；不是固定增加
  40 点，也不是对当前罪状总量乘 1.4。
- 罪状必须按动作/伤害来源读取，不能假设每个 hit 相同。当前技能详情与解包的动作级基准为：

  | 来源 | 基础罪状 |
  | --- | ---: |
  | 完整五段普通攻击 | 300 |
  | 极限反击 | 100 |
  | E「疑点锁定」 | 100 |
  | 下落攻击 | 70（当前实机详情） |
  | Q「恶名往复」自动增长 | 150/秒，即每 0.2 秒 30 |
  | QTE、Q 直接伤害、裁断分支伤害 | 0 |

- 2026-08-21 的静态 `DT_ChaosEffectFigure.Airattack_engry_Show` 仍为 30，与当前实机详情的下落攻击 70
  冲突；现版本重放优先采用实机详情 70，同时保留静态旧值作为版本差异证据，后续静态刷新后重新核对。
- `BP_ChaosLogicObj.DamageGENameAddSinsCoreKeyMap` 还为普通攻击各 GE 保存独立资源键。逐击能确认具体资源
  增量时优先使用正式增量；只有动作级证据时才使用上表总量。多目标动作只放大实际命中已标记目标所对应
  的那部分罪状，不能因其中一个目标有标记就把整次混合目标动作全部乘 1.4。
- Q 状态的每秒自动增长不是“攻击带标记目标时获得”，不因一觉乘 1.4。罪状上限为 1000，所有结果最终
  封顶。

### AWAKEN-1071-Effect2：罪名/恶行

- 卡厄斯攻击带追缉许可的目标时获得 `DefIgnore=+20%`，按攻击者防御穿透进入防御区。
- 只作用于卡厄斯本人对已标记目标造成的伤害；未标记目标、队友伤害以及与目标无关的资源增长不采用。

### AWAKEN-1071-Effect3：烟火

- 卡厄斯完成 Q 后获得 `CritDamageBase=+30%`，持续 20 秒；重复释放刷新，不叠层。
- Buff 在本次 Q 伤害结算后才获得，因此本次 Q 不享受该 30%，只投影给之后发生的可暴击伤害。持续时间按
  扣除时停的有效战斗时钟推进。

### AWAKEN-1071-Effect4：海潮漫延

- 卡厄斯击败带追缉许可的目标时，把该许可传递给附近 1 个未标记目标，并从传递时点重新计算完整 15 秒
  持续时间。
- 每次击败最多选择一个新目标，不向范围内全部敌人复制多份。原目标已经死亡，其标记随目标结束；传递后
  场上只新增一份新目标标记。

### AWAKEN-1071-Effect5：独见虚空

- 场上恰好只剩 1 个带追缉许可的目标时，卡厄斯对该目标获得 `DamageUpGeneralBase=+20%`。
- 条件只统计带标记目标；即使仍有其他未标记敌人，只要标记目标恰好一个，仍生效。第二个标记目标出现时
  立即失效，重新只剩一个时立即恢复。
- 与突破被动把标记目标通伤替换为 30% 的效果在同一通用增伤区加算；两者同时生效时合计 `+50%`，不是
  独立相乘。

### AWAKEN-1071-Effect6：伪原点

- 卡厄斯完成 Q 后，立即把当前罪状补到上限 1000；发生在本次 Q 伤害之后，供后续「裁断」消费。
- 这是设置当前资源值至上限，不是再增加 1000，也不乘一觉的 1.4；已经满值时不产生溢出资源。

### AWAKEN-1071-resonance_3：正义/正确

- 卡厄斯的 A、E、Q 有效技能等级统一 `+1`；基础等级 1～10，共鸣生效后的计算等级最高为 11。
- QTE、延滞结算及固定资源值不直接加级；裁断伤害属于 A 的正式分支时读取提升后的 A 等级。

### AWAKEN-1071-resonance_6：光明/白昼

- 带追缉许可的目标获得 `DamageResistanceReality=-10%`，作为目标侧相属性抗性降低，作用于全队对该目标
  造成的相属性伤害。
- 多目标分别维护；标记结束、目标死亡或脱战时撤销。它不是卡厄斯自身的属性穿透，也不作用于非相属性
  伤害。

### SKILL-1071-GA_Chaos071_Melee：追猎

- A、Z、下落攻击、极限反击及裁断分支按原轴实际伤害项使用卡厄斯攻击力的相属性直伤公式并正常暴击；
  延滞结束的反应伤害不是 A 本体，单独使用延滞持续时间公式。
- 各动作获得的罪状按正式动作/伤害来源值记录，一觉只把攻击已标记目标时本次实际获得量乘 `1.4`；罪状
  不作为伤害数值混入逐击。

### SKILL-1071-GA_Chaos071_Skill：疑点锁定

- E 的正式逐击使用卡厄斯攻击力和当前 E 等级倍率；追缉许可按实际目标分别建立，后续卡厄斯对该目标的
  通伤、防御无视与目标相抗降低按命中时状态投影。
- E 的目标标记、罪状获得和伤害是三类事件。多目标时不能因一个目标已标记，把同一次范围 E 的所有命中
  都按标记增益计算。

### SKILL-1071-GA_Chaos071_UltraSkill：罪业清偿

- Q 的正式伤害项使用卡厄斯攻击力和当前 Q 等级倍率；三觉暴击伤害 Buff 与六觉补满罪状都在 Q 完成后
  生效，不倒灌到本次 Q。
- Q 状态内的自动罪状增长和后续裁断分别记录；自动增长不属于攻击标记目标，不采用一觉的 1.4 倍。

### SKILL-1071-GA_Chaos071_QTE：强袭

- QTE 是使用卡厄斯攻击力的相属性直伤；它不直接获得罪状。若命中目标已有追缉许可，目标限定的通伤、
  防御无视和相抗降低仍按各自适用范围投影。

### REPLAY-1071：卡厄斯逐击、追缉许可与延滞投影

- 每个目标独立维护追缉许可、延滞起止时间和相关减抗；卡厄斯自身的标记目标增伤与防御无视只作用于其
  对该目标的逐击，全队相抗降低可作用于其他角色。
- 延滞结束伤害按实际有效持续秒数连续计算倍率，MVP 固定不暴击；运行时暴击证据可覆盖。原轴已经出现的
  裁断与标记转移保留，资源变化不在本期凭空生成新动作。
