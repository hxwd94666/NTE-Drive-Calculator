## 状态口径

- `结构化重放`：公式输入和消费者已结构化，仍可另外标注运行时状态置信度。
- `结构化估计`：数值公式已建模，但触发、层数、目标或状态来自推算。
- `固定轴估计`：保留真实逐击，用同技能、同类型、面板比值或零增量兜底。
- `已识别待建模`：身份明确，但尚无安全的反事实策略。
- `当前不影响固定轴`：只改变治疗、护盾、移动、资源或未来动作，不能误写为精确零收益。

## 人工审计方式

用户按稳定审计 ID 提供结论，例如 `AWAKEN-1003-Effect2`。每次确认至少记录：触发、状态时序、作用对象、
数值乘区、伤害消费者、是否改变逐击/循环，以及证据来源。人工结论写入 `review-notes.md`，自动重新生成目录
不会覆盖它。

角色常驻被动属于解释原始战斗与候选配置重放所必需的规则，但不是本期可单独开关的养成项。本期边际候选
不提供“移除常驻被动”；遇到会改变召唤物生命周期、资源循环、动作生成或覆盖顺序的被动，保留其真实轴与
角色专用机制，不为关闭被动凭空构造另一条动作轴。觉醒、技能等级、弧盘、空幕、驱动和面板属性仍按各自
可调整契约生成反事实。

44 条逻辑角色培养被动现由 `BattleCharacterPassiveService` 提供稳定目录，统一记录突破 2/4 解锁、机制类型、
重放适配器和固定轴策略。确定的常驻、驻场、技能限定和逐击叠层数值直接生成可解释 Buff 区间；浔 Q 终结段
由技能倍率证据层把基础倍率乘 2；法帝娅最大生命汲取继续复用目标生命适配器，并在未解锁对应突破被动时
停止归因和估算。哈尼娅黯星汲取、海月水母弹叠攻、真红盈蓄叠攻按正式逐击向后建立状态。改变目标状态、
资源循环、召唤生命周期或新增逐击的其余被动保留专用适配器身份；固定轴没有足够事件证据时沿用真实原击并
把未知机制增量估为 0，不伪装成已经精确重放。

24 条空幕二/四件套现由 `BattleEquipmentSuitService` 提供稳定目录。二件套继续读取正式 `modify_pack`；
四件套按已审计语义区分常驻、Q/E 动作、普通攻击逐击、队伍分属性命中、环合状态、独立叠层和当前不直接改变伤害的
护盾/治疗效果。空幕专用规则命中后不再同时遍历旧 generic Buff links，避免条件属性被常驻、任意技能结束
误触发。目标状态缺少敌方实例键、普通扣血缺少受击者映射时仍明确标作结构化估计。
