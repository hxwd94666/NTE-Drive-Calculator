# 薄荷「变身！超级薄荷！」创生范围专题审计

## 审计结论

薄荷突破 2 被动「变身！超级薄荷！」是**创生花命中范围加算**，不是伤害倍率，也不是范围乘算：

```text
创生花命中判定范围 = 原命中判定范围 + 400 个运行时距离单位
```

该被动不修改单朵创生花对同一目标的伤害，不会使同一朵创生花重复命中同一目标，也不应进入攻击、增伤、
防御、抗性、易伤、独立最终或环合专属伤害乘区。它在单目标固定轴上的直接伤害收益为 0；在多目标场景中，
只可能因为覆盖范围扩大而新增其他目标的命中。

现行反事实计算口径以[人工审计结论](review-notes.md#passive-1019-ga_mint_passive_1变身超级薄荷)为准；本文只记录
本次专题审计的证据链和排除过程。

## 冻结范围

- 静态 dataset：`cn_1_3_9_20260820`。
- 静态数据日期：`2026-08-20`。
- 被动 ID：`PASSIVE-1019-GA_Mint_Passive_1`。
- 运行时根 Buff：
  `/Game/Blueprints/Abilities/Player/Ability_019_Mint/PassiveEffect/Buff_Mint019_Passive1`。
- 审计对象：薄荷被动的作用类型，以及
  `GE_ActorReaction_1_1019_Damage` 中 `AtkRateBaseArray=2.0` 是否可以解释为范围倍率。

## 正向证据：正式字段明确是范围加算

`DT_ReactionExtendDataTable` 的角色 `1019` 条目给出：

| 字段 | 正式值 | 含义 |
| --- | ---: | --- |
| `AdditionalDamageRange` | `400.0` | 创生花伤害命中范围额外增加 400 |
| `NewDamageGE` | `null` | 不替换创生伤害 GE |
| `ReactionAbilityID` | `GA_Mint_Passive_1` | 对应薄荷突破 2 被动 |
| `ConditionArray` | `Buff_Mint019_Passive1` | 队伍具备该被动 Buff 时生效 |
| `Desc` | `蒲公英小球攻击范围扩大` | 静态机制说明 |

角色被动正式说明同时写明：“「创生」强化：「创生花」命中时伤害范围扩大。”字段名、数值、条件 Buff 与
说明互相闭合，没有伤害倍率或伤害 GE 替换语义。

`Buff_Mint019_Passive1` 本身是无限持续、目标聚合且上限 1 层的全局标记 Buff；具体的 `+400` 由环合扩展表
消费。因此不能因为根 Buff 没有普通属性 Modifier，就把该被动补写成伤害乘区。

## 排除证据：`AtkRateBaseArray=2.0` 不是范围倍率

`DT_SkillDamageData.GE_ActorReaction_1_1019_Damage` 确实存在十五档均为 `2.0` 的
`AtkRateBaseArray`，但不能将其解释成薄荷的范围倍率：

1. `AtkRateBaseArray` 位于技能伤害数据，是攻击倍率元数据；空间参数有独立的
   `AdditionalDamageRange` 字段。
2. 薄荷条目明确给出 `AdditionalDamageRange=400.0` 且 `NewDamageGE=null`，因此被动既不是“范围 ×2”，
   也不会切换到 `GE_ActorReaction_1_1019_Damage`。
3. 正式资产引用中，`GE_ActorReaction_1_1019_Damage` 被
   `ActorReaction_1_Manager_1075` 作为 `DefaultDamageGE` 消费；`GA_Reaction_1_New` 对该管理器的生成条件
   是 `Buff_Oneiroi075_Passive1`，即伊洛伊的被动链，而不是薄荷的 `Buff_Mint019_Passive1`。
4. `_1019` 只是该 GE 当前保留的资源名后缀，不能据此推断它仍归属薄荷。应以正式引用关系和生成条件判断
   当前消费者。

## 战报数值反证

已审计战报中，`GE_ActorReaction_1_1019_Damage` 的特殊创生样本使用正式等级环合曲线直接重放，不消费
`AtkRateBaseArray=2.0`：

```text
预计伤害 = ceil(等级环合基础值 × 环合强度区 × 防御区 × 抗性区 × 易伤区)
         = ceil(3375 × 1.6 × 0.588235 × 0.9 × 1)
         = 2859

实际伤害 = 2858
```

若再乘 `2.0`，预计值会接近 `5718`，与实际伤害形成约一倍高估。汇总的 326 个同类特殊创生重放样本中，
324 个绝对误差不超过 1%，绝对误差中位数约 `0.035%`、均值约 `0.047%`；这与“不消费 2.0”的公式一致。

## 反事实与展示口径

- 单目标：保留原逐击，薄荷该被动的单击伤害增量为 0。
- 多目标且有目标位置：按“原范围”和“原范围 + 400”分别计算命中集合，只新增进入扩大范围的副目标。
- 多目标但缺少位置：保留实际观测命中；移除被动时只能标记为空间估计，不能凭空删除或增加逐击。
- 逐击公式：不展示薄荷范围乘区，不把 `400`、`2.0` 或其他推测值乘入伤害。
- 解释文本：使用“创生花命中范围 +400”，避免使用容易被理解为乘算的“范围倍率”。

## 证据边界

- 当前战报逐击不包含完整三维目标位置和每朵创生花的碰撞半径，无法仅凭逐击完成多目标空间反事实。
- `AtkRateBaseArray=2.0` 在技能伤害表中真实存在；本结论只确认它不被当前环合曲线伤害路径消费，也不是薄荷
  被动的空间参数，不把它泛化为所有运行时均无消费者。
- 本审计不改变原始战报事实，不推测未观测到的副目标命中，也不修改现有计算实现。
