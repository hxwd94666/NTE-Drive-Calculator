# 弧盘精炼反事实文本盘点

> 相同弧盘的五个精炼等级合并为一个审计单元；具体数值仍逐级列出。

当前共 `49` 组精炼效果、`245` 个精炼等级。

## 当前落模状态

49 组精炼效果现在全部具有唯一的专用 Service 所有者，不再由通用 Blueprint 引用闭包猜测是否激活：

- 22 组既有专用模型继续负责前后台、受击、治疗、逐目标、显式暴击、周期、随机和召唤语义；
- 16 组伤害优先补全模型负责常驻攻击/增伤、A/E/Q/QTE 消费者、E/Q/逐击叠层、技能消费与精炼联动；
- 11 组生存、资源或运行时条件模型明确保存缺失事实，包括玩家生命、护盾、方斯、击杀、削韧、队伍属性、
  主动调弧和随机分支。条件缺失时只展示参数与缺口，不进入伤害公式，也不补造逐击。

预备备的司令虎符按正式令牌状态机推断：E 动作实际结束时提供左虎符，正式 Q begin 提供右虎符，猫协同
伤害碎片不作为 Q；十五个有效战斗秒内凑齐双符时，从第二枚令牌到达时立即建立十秒区间，不等待伤害阶跃。
Boss 增伤仍要求正式 Boss 身份；当前范围的解析目标经正式怪物目录全部确认为 Boss 时直接消费条件，否则
保留未解析而不显示为零收益。行进于时间之外的 Q 暴伤只覆盖消费荒时的该次 Q；满三层产生的无视防御是
独立的七十秒自身全伤害区间，不继承 Q 伤害标签。
